# UE5.7 地编 + 虚拟拍摄 学习路径（中文版界面适配）
## —— 专为 AI 空间控制器定制的精简管线

---

## 前置认知：你不需要学整个 UE5

UE5 是一个 100GB+ 的巨兽。但你的目标不是做游戏，是**搭场景 → 摆机位 → 出快照 → 喂 AI**。

```
你需要学的：                         你不需要学的：
  ✅ 基础界面操作                        ❌ C++ 编程
  ✅ 放置资产（拖拽模型到场景）            ❌ 蓝图可视化编程
  ✅ 灯光系统（定向光源/点光源/天空光照）    ❌ AI 行为树 / NPC 逻辑
  ✅ 电影摄像机（CineCameraActor）        ❌ 物理碰撞 / 破坏系统
  ✅ 序列 Sequencer 关键帧动画             ❌ 材质编辑器（用现成的就行）
  ✅ 渲染输出（高分辨率截图）              ❌ Niagara 粒子特效
  ✅ 场景模板保存                        ❌ 多人网络复制
```

**你需要的是一套"摄影棚"技能，不是一套"游戏开发"技能。**

## 第一课：启动和界面

### 1.1 启动 UE5.7

```
方式一：打开 Epic Games Launcher
        → 左侧点"虚幻引擎"
        → 顶部点"库"
        → 找到 5.7 版本 → 点"启动"

方式二：直接双击 D:\UE5\UE_5.7\Engine\Binaries\Win64\UnrealEditor.exe
```

### 1.2 创建新项目

```
① 打开后看到项目浏览器
② 模板选择：点 "游戏" 分类 → 选 "空白"（最左边那个空的）
                              ↑ 不要选第一人称/第三人称/载具那些！
③ 项目设置（右侧栏）：
   • 蓝图 / C++：选 "蓝图"（不要选 C++）
   • 目标平台：桌面
   • 画质预设：最大值
   • 初学者内容包：✅ 勾选（这个超级重要！自带基础模型和材质）
   • 光线追踪：✅ 勾选
④ 项目位置：选 D 盘，比如 D:\UE5_Projects\MyFirstScene\
   ↑ 千万别放 C 盘，一个空项目就 2GB+
⑤ 项目名称：用英文，比如 MyFirstScene
⑥ 点右下角 "创建" 按钮
```

### 1.3 界面核心区域（打开项目后看到的）

```
┌──────────────────────────────────────────────────┐
│ 顶部菜单栏 （文件、编辑、窗口、帮助...）              │
├────────────┬─────────────────────┬───────────────┤
│            │                     │               │
│  内容浏览器 │      视口           │  世界大纲视图   │
│  (左下角)  │    (中间大窗口)      │  (右上角)      │
│            │                     │               │
│  你的所有   │   操作场景的         │  场景中所有     │
│  模型/材质  │   主要工作区         │  物体的列表     │
│  都在这里   │                     │  按名称排列     │
│            │                     │               │
├────────────┴─────────────────────┴───────────────┤
│  细节面板（右下角 / 屏幕下方）                        │
│  选中任意物体后，这里显示它的所有属性                  │
└──────────────────────────────────────────────────┘
```

**如果某个面板找不到：** 顶部菜单 → "窗口" → 找到对应的面板名称并点击。

### 1.4 视口操作（先练这个，其他都是后话）

```
鼠标右键按住 + WASD .............. 像打 FPS 一样在场景里飞
鼠标右键按住 + Q ................. 往下降
鼠标右键按住 + E ................. 往上升
鼠标右键按住 + 滚轮上下 ........... 调整飞行速度（注意屏幕右上角的速度提示）
鼠标滚轮 ........................ 拉近拉远
鼠标左键按住 + 拖动 .............. 旋转视角
鼠标中键按住 + 拖动 .............. 平移视角

选中一个物体后：
  F 键 ........................... 镜头聚焦到该物体
  Alt + 鼠标左键按住拖动 .......... 围绕该物体旋转观察

G 键 ............................ 切换"游戏视图"（隐藏所有编辑图标，看纯画面）
Ctrl + 空格 ..................... 弹出内容浏览器
```

**花 15 分钟在空场景里飞一飞。** 这是 UE5 里回报率最高的 15 分钟。

## 第二课：地编基础（20 分钟出第一个场景）

### 2.1 快速放置基础几何体

```
方式一：拖拽放置（最快）
  ① 按 Ctrl + 空格 打开内容浏览器
  ② 左侧目录树展开：Content → StarterContent → Shapes
  ③ 你会看到：立方体(Cube)、球体(Sphere)、圆柱体(Cylinder)、锥体(Cone)
  ④ 把 "Cube" 直接拖进视口 → 完成！

方式二：菜单放置
  顶部菜单 → Actor → 放置Actor → 形状 → 立方体
```

### 2.2 把立方体变成地板

```
① 选中场景中的立方体
② 看右下角的 "细节" 面板
③ 找到 "变换" 分类 → "缩放" 那一行
④ 把 X 改成 8.0，Y 改成 8.0，Z 改成 0.1
⑤ 回车确认 → 一个大地板就出来了！
```

### 2.3 搭四面墙（2 分钟）

```
① 再拖一个 Cube 进来
② 缩放改成：X=8.0, Y=0.2, Z=3.0  → 这是一面墙
③ W 键（移动模式）→ 拖动到地板边缘
④ 按 End 键 → 墙自动落到地板上（超常用！）
⑤ 按住 Alt 键拖动墙 → 复制出第二面墙 → 放到对面
⑥ 同样方法做两面短墙：X=0.2, Y=8.0, Z=3.0 → 放到另外两边
⑦ 现在你有一个 8x8 米的房间了
```

### 2.4 放道具（StarterContent 自带的）

```
内容浏览器路径（注意：文件夹名可能是英文，UI是中文）：

  Content/StarterContent/Props/
    ├── SM_Chair      → 椅子
    ├── SM_TableRound → 圆桌
    ├── SM_Lamp       → 台灯
    ├── SM_Door       → 门
    ├── SM_PlantPot   → 花盆
    └── SM_Books      → 书

直接把这些拖进场景就行了！
拖进去之后按 End 让它们落地。
```

### 2.5 移动 / 旋转 / 缩放

```
W 键 → 移动模式（出现三个彩色箭头：红X / 绿Y / 蓝Z）
E 键 → 旋转模式（出现三个彩色弧线）
R 键 → 缩放模式（出现三个彩色方块）

实用技巧：
  • 只拖动某个箭头 = 沿该方向移动
  • 拖动两个箭头之间的小方块 = 沿平面移动
  • 按 End 键 = 物体落到下方最近的面上（神器！）
  • 按住 Ctrl 拖动 = 按网格吸附移动
  • 选中物体后 → 细节面板里可以直接输入精确数值
```

### 2.6 ⭐ 实战练习：5 分钟搭一个客厅角落

```
目标：能作为 AI 生成参考场景的空间

步骤：
  ① Cube → 缩放 8, 8, 0.1 → 地板
  ② Cube → 缩放 8, 0.2, 3 → 一面墙（放到地板边缘，按 End）
  ③ 按住 Alt，把墙拖到另一边 → 第二面墙
  ④ Cube → 缩放 2, 2, 0.5 → 桌子（放角落，End 落地）
  ⑤ 从 Props 拖 SM_Chair → 放桌子旁
  ⑥ 从 Props 拖 SM_Lamp → 放桌上
  ⑦ Ctrl+S → 保存当前关卡，命名为 "Scene_LivingRoom"

完成了。不美，但有空间关系。这对 AI 来说就够了。
```

## 第三课：灯光系统（决定场景的情绪）

**这一课是 AI 命中率的核心。** 灯光信息会通过快照传递给 Agent Pipeline。

### 3.1 五种灯光类型（中文版名称）

| 灯光类型（中文版） | 用来干嘛 | 生活类比 |
|-------------------|---------|---------|
| **定向光源** | 太阳光/月光，从无穷远处照来的平行光 | 窗户照进来的阳光 |
| **点光源** | 灯泡，从一个点向四面八方发光 | 台灯、吊灯、蜡烛 |
| **聚光源** | 舞台聚光灯，有方向有角度 | 手电筒、射灯、追光 |
| **矩形光源** | 柔光箱，大面积均匀发光 | 摄影棚柔光箱、窗户反光 |
| **天空光照** | 环境光，包裹整个场景的均匀照明 | 阴天的环境光 |

### 3.2 怎么放灯光

```
方式一：拖拽（推荐）
  内容浏览器 → 搜索框输入 "光源"
  → 把需要的灯光类型拖进视口

方式二：菜单
  顶部菜单 → Actor → 放置Actor → 光源
  → 选择类型（定向光源 / 点光源 / 聚光源 / 矩形光源 / 天空光照）
```

### 3.3 最重要的灯光参数（选中灯光 → 看细节面板）

```
定向光源（太阳光）——中文版参数名：

  强度(Intensity)：3-5 lux（默认 10 通常太亮，降到 3-5）
  光源颜色(Light Color)：点一下色块 → 暖色/冷色随便选
  ↑ 旋转灯光方向 = 改变阳光角度 = 整个场景的情绪全变了


点光源（灯泡/台灯）——中文版参数名：

  强度(Intensity)：1-3
  衰减半径(Attenuation Radius)：控制光能照多远
  光源颜色(Light Color)：2700K 左右是暖黄灯泡，6000K 是冷白日光灯


矩形光源（柔光箱）——最接近摄影棚效果：

  强度(Intensity)：3-8
  光源宽度(Source Width) / 光源高度(Source Height)
  ↑ 面积越大，阴影越柔和，越像真实影棚的柔光箱
```

### 3.4 如果场景太暗或太亮

```
场景太暗怎么办：
  ① 放一个 天空光照 → 强度调到 2-5 → 整个场景立刻亮起来
  ② 放一个 后期处理体积(Post Process Volume)
     → 细节面板搜 "曝光"
     → 计量模式 改成 "手动"
     → 曝光补偿 调到 1.0-3.0

场景太亮怎么办：
  ① 选中定向光源 → 强度从 10 降到 3
  ② 天空光照 → 强度从 1 降到 0.5
```

### 3.5 快速打光练习（5 分钟）

```
目标：给刚才的客厅场景打光

步骤：
  ① 选中场景中已有的定向光源 → 旋转它，让光从"窗户"方向照进来
     强度调成 4，颜色选偏暖的淡黄色
  ② 放一个 点光源 在台灯位置
     → 强度 2，颜色选暖黄色（2700K 那种感觉）
     → 衰减半径 300
  ③ 放一个 天空光照 → 强度 1.5
  ④ 现在场景应该是"黄昏室内有盏灯"的感觉

Ctrl+S 保存
```

## 第四课：电影摄像机（虚拟摄影机）

**这是整个学习路径的核心中的核心。** 你 TapNow 里 ShotNode 的每一个字段，都对应电影摄像机的一个参数。

### 4.1 三种放摄影机的方法

```
方法一：Ctrl+数字（最快）
  ① 在视口中飞到你想拍的位置和角度
  ② 按 Ctrl + 1
  ③ 一个摄像机自动出现在你的视角位置！
  ④ 继续飞到第二个角度 → Ctrl+2 → 第二个摄像机
  ⑤ 以此类推

方法二：从菜单创建
  顶部菜单 → Actor → 放置Actor → 过场动画 → 电影摄像机Actor(CineCameraActor)

方法三：从内容浏览器创建
  Ctrl+空格 → 搜索 "CineCamera" → 把 CineCameraActor 拖进视口
```

### 4.2 核心摄像机参数（选中摄像机 → 看细节面板）

```
当前焦距(Current Focal Length) —— 中文版就这样叫：
  • 24mm  → 广角，空间感强，室内常用，画面边缘会拉伸
  • 35mm  → 接近人眼感觉，自然
  • 50mm  → 标准镜头，和人眼聚焦范围接近
  • 85mm  → 中长焦，空间压缩感，人像常用
  • 135mm → 长焦，远处拍过来，空间压缩强
  • 200mm+→ 超长焦，超远距离拍摄

当前光圈(Current Aperture) —— 中文版叫 "当前光圈"：
  • f/1.4 → 超大光圈，背景超虚，主体突出
  • f/2.8 → 大光圈，背景虚化明显
  • f/5.6 → 中等，部分背景虚化
  • f/8   → 小光圈，大部分都清晰
  • f/16  → 极小光圈，前后都清晰（适合大场景/风景）

手动对焦距离(Manual Focus Distance)：
  控制画面中最清晰的位置在哪里
  一般设为你想要的主体距离（单位是厘米）
```

### 4.3 实时预览摄像机画面

```
选中场景中的电影摄像机
→ 右键点击摄像机 → 选 "驾驶"（Pilot）
→ 现在你的视口变成了摄像机画面！
→ 你可以在这个"摄像机视角"里：
    • WASD 移动摄像机
    • 鼠标旋转摄像机
    • 就跟用真实摄影机一样
→ 按 G 键隐藏所有图标 → 纯画面预览

退出驾驶模式：
  视口左上角点 "弹出(Eject)" 按钮，或直接选中别的物体
```

### 4.4 摄影机练习：同一场景，三种镜头

```
目标：同一个客厅，用三种不同摄像机表达完全不同的感觉

镜头 A — 全景(Establishing Shot)：
  摄像机放房间角落 → 24mm → f/8
  看到整个房间空间关系
  → 这是"告诉观众在哪儿"的镜头

镜头 B — 中景(Medium Shot)：
  摄像机对准桌子和椅子 → 50mm → f/4
  中等距离
  → 这是"事件发生的地方"

镜头 C — 近景(Close Up)：
  摄像机贴近台灯 → 85mm → f/2.8
  背景虚化，主体明确
  → 这是"气氛/细节"的镜头

每摆好一个：Ctrl+1 / Ctrl+2 / Ctrl+3 分别保存
```

## 第五课：序列 Sequencer（虚拟拍摄录制）

Sequencer 就是 UE5 里的视频编辑器，相当于 Pr/AE 的时间轴。你可以用它做摄像机动画、多机位切换。

### 5.1 创建 Sequencer

```
顶部菜单 → 过场动画 → 添加关卡序列(Add Level Sequence)
→ 弹窗让你命名和选择保存位置 → 确认

你会看到 Sequencer 编辑器窗口打开，底部有时间轴（和视频剪辑软件一模一样）。
```

### 5.2 把摄像机放进 Sequencer

```
方式一（最简单）：
  ① 在世界大纲视图（右上角列表）里找到你的电影摄像机
  ② 直接把它从大纲拖进 Sequencer 的轨道区域
  ③ 松手，摄像机轨道就创建好了

方式二：
  Sequencer 工具栏 → "+轨道(+Track)" 按钮
  → "Actor至Sequencer(Actor to Sequencer)"
  → 在弹出的列表里选你的摄像机
```

### 5.3 设置关键帧——让摄像机动起来

```
摄像机轨道展开后，你会看到 "变换(Transform)" 子轨道

步骤：
  ① 把时间轴底部的红色竖线（时间指针）拖到 0 秒处
  ② 在视口中把摄像机调整到你想要的位置和角度
  ③ 在 Sequencer 里点变换轨道旁边的 "+ 关键帧" 按钮
     （或者直接按 Enter 键）→ 0 秒位置出现一个关键帧标记
  ④ 把时间指针拖到 3 秒处
  ⑤ 在视口中把摄像机移动到新位置
  ⑥ 再按 Enter → 3 秒处自动加关键帧
  ⑦ 点 Sequencer 的播放按钮 ▶ → 摄像机在 3 秒内平滑移动！

想让它动得快？把关键帧间距缩小（1 秒从 A 到 B）
想让它动得慢？把关键帧间距拉大（10 秒从 A 到 B）
```

### 5.4 多摄影机切换

```
场景里放了多个摄像机（CameraA、CameraB、CameraC）

在 Sequencer 里：
  ① 点 "+轨道" → "摄像机切换轨道(Camera Cut Track)"
  ② Camera Cut 轨道出现了
  ③ 把 CameraA 从大纲拖到 Camera Cut 轨道的 0-2 秒处
  ④ 把 CameraB 拖到 2-4 秒处
  ⑤ 把 CameraC 拖到 4-6 秒处
  ⑥ 播放 → 第 0-2 秒 CameraA，第 2-4 秒切到 CameraB，以此类推

这就是"多机位拍摄"的虚拟版。
```

### 5.5 导出画面（这就是 AI Pipeline 的输入！）

```
方法一：高分辨率截图（最常用，单帧）

  ① 视口左上角有个小三角 ▼ → 点击
  ② 选择 "高分辨率截图"
  ③ 弹出的窗口里：
     分辨率倍数：2x 或 3x
     ↑ 如果视口是 1024px → 2x = 2048px，3x = 3072px
  ④ 点 "截图" 按钮
  ⑤ 图片保存到：你的项目文件夹/Saved/Screenshots/

方法二：从 Sequencer 渲染多帧

  在 Sequencer 窗口里：
  ① 点工具栏上的电影拍板图标 🎬（渲染为视频/图像序列）
  ② 输出格式选 "PNG 序列"
  ③ 分辨率自己定
  ④ 帧范围：当前帧 or 整个时间范围
  ⑤ 点 "渲染" → 等几秒 → 完成
```

**这个截图就是你喂给 AI 的"空间控制信号"。** 一张 UE5 快照 = 精确的空间关系 + 灯光方向 + 摄影机构图 + 物体遮挡。比任何 Prompt 都准确。

## 第六课：出人和摆姿势（虚拟拍摄必须）

### 6.1 让 UE5 自带的小白人出现

UE5 自带的小白人叫 Manny，但默认是隐藏的，需要两步：

```
第一步：打开引擎内容显示

  内容浏览器 → 右上角点 "设置"(Settings)（小齿轮图标）
  → 勾选 "显示引擎内容"
  → 勾选 "显示插件内容"

第二步：搜索小白人

  内容浏览器搜索框输入：SKM_Manny 或 SK_Mannequin
  → 看到 "SKM_Manny" 这个资产 → 把它拖进场景
  → 小白人出现了！
```

### 6.2 如果上面搜不到（新项目可能没有）

```
添加第三人称内容包：

  ① 内容浏览器 → 点绿色的 "+ 添加" 按钮
  ② 选择 "添加功能或内容包..."
  ③ 在弹出的窗口里选 "第三人称" 内容包
  ④ 点 "添加到项目"
  ⑤ 等几秒加载完 → 左边目录里会出现 Content/ThirdPerson/
  ⑥ 展开 → 找到小白人 → 拖进场景
```

### 6.3 让人物摆出想要的姿势

```
选中小白人 → 看细节面板 → 搜 "动画"

找到：
  "动画模式(Animation Mode)" → 改成 "使用动画资产(Use Animation Asset)"
  "要播放的动画(Anim to Play)" → 下拉菜单：
    • 搜 "idle" → 站着不动
    • 搜 "sit"  → 坐着
    • 搜 "walk" → 走路
    • 搜 "lean" → 靠着

选了之后点 Sequencer 的播放 ▶，小人就会做动作。
```

### 6.4 如果只为了 AI 构图，更省事的做法

```
AI 不需要看到精致的小白人——AI 只需要知道：
  "这个位置有个东西，大概占画面这么多，人和环境比例是 X"

所以更省事的做法：
  ① 拖一个 圆柱体(Cylinder) → 缩放让它的比例像个人（细长）
  ② 拖一个 球体(Sphere) → 放在圆柱体上面当"人头"
  ③ 把它们放一起 → 这就是你的"火柴人占位"
  ④ 在场景任何位置复制粘贴 → 快速填充人物位置
  ⑤ 然后按场景需求摆摄影机

这个占位法对 AI 的构图指导效果和精致模型是一样的。
```

## 第七课：快捷工作流（组合技）

### 7.1 最快出场景模板流程

```
新建项目（空白 + 勾选"初学者内容包"）
     │
     ├→ 拖 Cube → 改缩放 → 搭地板和墙（2 分钟）
     ├→ 从 Props 拖家具、装饰品（5 分钟）
     ├→ 放 3-4 盏灯 + 调颜色和强度（3 分钟）
     ├→ 放圆柱体+球体当人物占位（2 分钟）
     ├→ 飞视角 → Ctrl+数字 → 设 3-5 个摄像机（5 分钟）
     ├→ 高分辨率截图 → 导出（2 分钟）
     │
     └─→ 总计 15-20 分钟一个可用的场景模板
```

### 7.2 建议的五个基础模板

```
1. 室内_公寓        — 中小空间，日常感
2. 室内_摄影棚       — 纯色背景+专业灯光，产品/人像拍摄风
3. 户外_城市街角     — 建筑+街道+路灯
4. 户外_自然风景     — 山/树/水（用 StarterContent 的石头和树）
5. 概念_极简空间     — 大面积单色+几何体，给 AI 最大想象空间
```

### 7.3 不需要操心的事情（非游戏项目的特权）

```
你的场景不需要 60fps：
  ✅ 可以放高面数模型（不卡就行）
  ✅ 可以用高清贴图
  ✅ 不需要 LOD（远景简化）
  ✅ 不需要碰撞体
  ✅ 不需要优化 Draw Call

只要能渲染出一帧 1024px 的截图，你就赢了。
```

### 8.1 全流程：UE5 快照 → AI 生成

```

│ ImageGenerate   │
│ Node            │
└────────┬────────┘
         │ I2I 模式 + UE5 快照作为参考图
         │ ShotNode 填写电影元数据
         ▼
┌─────────────────┐
│ 4-Agent Pipeline │

         │
         ▼

│ (GPT Image2等)  │
└─────────────────┘
```

### 8.2 ShotNode 字段 ↔ UE5 摄像机参数对照表

| ShotNode 字段 | 在 UE5 里怎么实现 | 简单操作 |
|-------------|----------------|---------|
| **景别** | 摄像机距离 + 焦距 | 远景=远+24mm；近景=近+85mm |
| **镜头** | 当前焦距 | 直接输入：24/35/50/85/135 |
| **机位角度** | 摄像机旋转 | 仰拍=往上转；俯拍=往下转 |
| **运镜** | Sequencer 关键帧 | 推拉摇移 = 两个关键帧之间的位移 |
| **主光方向** | 定向光源旋转 | 顺光=灯光在摄像机后面；逆光=在前面 |
| **氛围** | 灯光色温 + 后期处理体积 | 暖=偏黄灯光；冷=偏蓝灯光 |
| **色彩** | LUT / 后期处理体积 | 色彩倾向在后期处理体积里调 |
