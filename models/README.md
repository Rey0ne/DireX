# 人物白模

将以下 7 个 GLB 文件放入此目录：

| 文件名 | 姿态 |
|--------|------|
| `stand.glb` | 站立 |
| `walk.glb` | 行走 |
| `run.glb` | 跑步 |
| `sit.glb` | 坐姿 |
| `squat.glb` | 蹲姿 |
| `lie.glb` | 卧躺 |
| `fight.glb` | 格斗 |

## 获取方式

1. 打开 [mixamo.com](https://mixamo.com)，注册 Adobe 免费账号
2. 选角色（推荐 Y Bot / X Bot，接近白模效果）
3. 分别选 7 个姿态/动画，在动画开头暂停 → Download → FBX → 选 "Without Skin" → 下载
4. Blender 导入 FBX → 导出 glTF 2.0 (.glb) → 放入此目录

每个姿态对应一个文件，文件名必须和上表一致。
